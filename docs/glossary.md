# 用語集

システムで使用する用語の定義です。
設計書・コード内で用語を統一するために参照してください。

## ビジネス用語

| # | ビジネス用語 | 説明 |
|---|-------------|------|
| 1 | 内部ID | トレーニング機関内で使用するクライアントの識別番号。DBの主キーとは別に、業務上で使う番号として保持する。新規登録時は現在の最大値+1で自動採番、編集画面で手動変更も可能 |
| 2 | 所感 | トレーナーが記録する所見・気づき。トレーナー間で共有するがクライアントには非開示 |
| 3 | 音声ファイル | 録音またはアップロードされた音声の実ファイル。音声記録の一種で、文字起こしの入力となる |
| 4 | 文字起こし | 音声ファイルをテキストに変換すること。Whisper APIを使用 |
| 5 | 要約 | 文字起こしテキストをAIで短くまとめたもの。Claude APIを使用 |
| 6 | 電話番号 | クライアントの連絡先。緊急時に最初に連絡する番号 |
| 7 | 電話番号（予備） | クライアントの連絡先のうち 2 つ目。1 つ目がつながらないときに使う。携帯・自宅・家族の番号など、用途は問わない |
| 8 | メールアドレス登録用 URL | トレーナーが発行し、クライアント自身にメールアドレスを登録してもらう URL。有効期限は発行から 3 日。**この期限が初回設定完了までの全体の期限**となる |
| 9 | ログイン用リンク | 登録されたメールアドレスに届く、初回設定用のリンク。**リンクを開くとクライアントがログインした状態になる**（ログインさせる働きを持つ）。有効期限は独立して持たず、**対応するメールアドレス登録用 URL の期限をそのまま引き継ぐ**（お客様がメールアドレスを登録した時点から数え直さない） |
| 10 | 初回設定 | クライアントがログイン用リンクから、パスワードと基本情報を設定すること |
| 11 | メールアドレス確認リンク | 登録情報設定画面からメールアドレスを変更する際、**新しいアドレスに送る**リンク。**メールアドレスを切り替えるだけの役割**で、ログインさせる働きは持たない。ログイン用リンク（No.9）とは性質が異なる別のもの。他のトークンとは無関係に発行されるため、**独立した有効期限**（3 日）を持つ |
| 12 | メールアドレスなし | クライアントの状態のひとつ。メールアドレスが未登録で、有効なメールアドレス登録用 URL もない状態。メールアドレス登録用 URL を発行するとメールアドレス登録待ちに遷移する |
| 13 | メールアドレス登録待ち | クライアントの状態のひとつ。有効なメールアドレス登録用 URL が発行済みで、まだお客様がメールアドレスを登録していない状態。お客様がメールアドレスを登録すると初回設定待ちに遷移する |
| 14 | 初回設定待ち | クライアントの状態のひとつ。メールアドレスは登録済みだが、パスワードがまだ設定されていない状態。お客様が初回設定を完了すると利用中に遷移する。**（判定ルール：メールアドレスがあり、かつ有効なメールアドレス登録用 URL もあるケースはこちらを優先）** |
| 15 | 利用中 | クライアントの状態のひとつ。メールアドレスとパスワードの両方が登録済みで、クライアントが閲覧機能にログインできる状態。トレーナーはこの状態のときだけ「メールアドレスを削除」できる |
| 16 | 登録情報設定 | ログイン中のお客様が、自分の連絡先（電話番号・住所）・メールアドレス・パスワードを変更する操作。専用の登録情報設定画面（S-1406）を通じて行う。メールアドレスの変更は新しいアドレスへ「メールアドレス確認リンク」（No.11）を送り、リンクが開かれた時点で切り替える |
| 17 | パスワード再設定リンク | パスワードを忘れたお客様がログイン画面（S-1401）の「パスワードを忘れた方」から申し込みを行った際、登録アドレスに届く**新しいパスワードを設定するためのリンク**。**ログインさせる働きは持たない**（ログイン用リンク No.9 との違い）。**メールアドレスも変えない**（メールアドレス確認リンク No.11 との違い）。他のトークンとは無関係に発行されるため、**独立した有効期限**（3 日）を持つ |

## 技術用語

| 用語 | 説明 |
|------|------|
| Whisper API | OpenAIが提供する音声文字起こしAPI。日本語を含む多言語に対応 |
| Claude API | Anthropicが提供する大規模言語モデルAPI。要約に使用（Haiku 4.5） |
| 非同期処理 | 処理の完了を待たずに次の操作に進める方式。文字起こし・要約の処理に使用し、ブラウザのタイムアウトを防ぐ |
| キュー（Job） | Laravelの非同期処理の仕組み。バックグラウンドでAPIの処理を実行する |
| MediaRecorder API | ブラウザ標準のAPIで、マイクからの音声をリアルタイムで録音する機能 |
| API（Application Programming Interface） | 外部システムとのデータ受け渡し口 |
